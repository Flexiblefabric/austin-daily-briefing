# ADB newsletter brand assets

These files are the approved production identity assets for Austin Daily Briefing newsletter work.

## Files

- `adb-masthead.svg` — canonical outlined vector master.
- `adb-masthead.png` — 900×220 Paper-background PNG.
- `adb-masthead@2x.png` — 1800×440 high-density PNG.
- `adb-mark.svg`, `.png`, `@2x.png` — compact mark for light backgrounds.
- `adb-mark-reversed.svg`, `.png`, `@2x.png` — reversed compact mark for the Charcoal footer.

The marks do not depend on remote font loading. Do not reconstruct the masthead in live HTML text.

Alt text:
- Masthead: `Austin Daily Briefing`
- Compact mark: `ADB` when surrounding text does not already identify the publication.

Approved colors:
- Charcoal `#181818`
- Signal Red `#DB2D2D`
- Paper `#FFFEFA`

Usage is governed by `docs/design-system.md` and `docs/newsletter-component-spec.md`.

Source package: approved ADB DEV brand package dated 2026-09-20. Font files are intentionally not duplicated here because the committed marks are outlined or rasterized and do not require them.
